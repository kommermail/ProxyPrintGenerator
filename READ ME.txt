ProxyPrintGenerator for Windows
================================

Print playtest proxies of your decks: paste a deck list, pick printings,
and get print-ready sheets on Letter, A4 or any paper size your printer
lists (3x3 cards at true size on Letter and A4, 4x4 on 11x17 and A3,
with cutting guides), as PDF, PNG or JPEG, or print straight from the app.

A little vibrance magic makes them look like the real thing: flip on
Auto on the realism sticker and the app boosts the colors and lifts the
midtones, so home prints come out bright and punchy instead of dull.

RUNNING IT
- Unzip anywhere and double click ProxyPrintGenerator.exe.
  Nothing to install; Windows 10 or 11, 64 bit.
- The first time, Windows SmartScreen may say "Windows protected your PC"
  because the app isn't code signed. Click "More info", then "Run anyway".

UPDATES
- The first time you open the app, it asks whether it may check GitHub
  for a newer version each time it opens. Say no and it never will.
- If a newer version is out, it shows what's new and asks first. "Update
  now" downloads it from this app's GitHub Releases page, checks it
  against the checksum GitHub lists, and restarts into it. Your decks
  and settings stay as they are.
- Check by hand, or turn the check on or off, at the bottom of the Deck
  Library.
- If the app is in a folder it can't write to (such as Program Files),
  it can't update itself; download the new zip instead.

IS IT SAFE? YES.
That blue "Windows protected your PC" box (it may also say the app
could harm your computer) shows up for almost any new app that isn't
code signed. Code signing is a paid certificate that small free apps
often don't have. The warning is normal and expected for this app.
It does not mean anything is wrong with it.
- Every release is tested before it goes out: on the developer's own
  PC, and on a fresh Windows machine in the cloud, where it is also
  scanned with Microsoft Defender.
- The full source code is public, so anyone can see exactly what it
  does: https://github.com/kommermail/ProxyPrintGenerator
- The app connects to Scryfall, for card data and images. It connects
  to GitHub only if you turn on automatic update checks or click "Check
  for updates", and to no other website: it refuses to download from
  anywhere else. Every connection is secure (HTTPS). The Ko-fi button
  opens in your web browser, and only when you click it.
- Apart from updating itself when you say so, it doesn't install
  anything, doesn't change any Windows settings, and doesn't collect
  any personal information.
- Only download it from the GitHub Releases page. Each release lists a
  checksum, so you can confirm your copy is the real one.

WHERE THINGS GO
- Finished builds:  Documents\ProxyPrintGenerator\
- Your decks:       %APPDATA%\ProxyPrintGenerator\decks.json
- Update choice:    %APPDATA%\ProxyPrintGenerator\updates.json
- Paper and fit:    %APPDATA%\ProxyPrintGenerator\layout.json
- Image caches:     %LOCALAPPDATA%\ProxyPrintGenerator\  (safe to delete)

PRINTING TIPS
- Print at actual size. The app's own Print button always does this.
- Most home inkjets print at 600 dpi, so a 600 dpi build ("600") is all
  they can use; higher scales are for print shops.
- If a card edge gets clipped, turn on Fit to my printer (under Paper
  and printer) and pick your printer, or use Shift up.
